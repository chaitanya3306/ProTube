# Store listing copy (Edge, Firefox, Opera, Chrome)

**Name:** ProTube: Productive YouTube

**Short description (under 132 chars):**
A focused YouTube feed of your chosen topics, with clickbait filtering, Shorts controls, and distraction-free watch pages.

**Long description:**
ProTube replaces YouTube's algorithmic homepage with a quality-scored feed of the topics you choose, and filters out clickbait and low-value videos.

- Quality-scored, non-repeating feed built from your topics
- Clickbait & Value Detection: title, engagement and description signals, a "Value" badge with reasons, adjustable sensitivity (Strict / Balanced / Lenient)
- Teach it: mark any video "Good" or "Clickbait" and it adapts locally
- Watch-page shield: hide the sidebar, collapse comments, block end screens, redirect Shorts
- Zen Mode, Watch Queue, channel muting, focus timer
- Works instantly with no setup (RSS starter mode); optional free YouTube API key for wider discovery
- 100% local. No analytics, no tracking, no accounts, no servers.

**Category:** Productivity

## Permission justifications
- `storage`: saves your topics, settings, watch queue and learned feedback on your device.
- `youtube.com`: required to show the focus feed on YouTube and apply the watch-page shield.
- `www.googleapis.com`: optional YouTube Data API v3 calls using the user's own key.
- `api.openai.com` (optional, requested at runtime only): used only if the user turns on the AI Judge and supplies their own key; sends only video title, channel, duration and a short description excerpt for borderline videos.

## Privacy answers
- Data collected: none. Everything stays in browser storage; nothing is sent to the developer.
- Remote code: none.
- Privacy policy: link to PRIVACY.md in the repository.

## Notes for Mozilla reviewers
- All dynamic strings inserted via `innerHTML` pass through `escapeHtml` / `escapeAttr` (see `js/content.js`, `js/options.js`); `web-ext lint` reports 0 errors and only UNSAFE_VAR_ASSIGNMENT warnings.
- No build step: the uploaded ZIP is the unminified source.
- The Firefox package is generated by `scripts/package_firefox.py` (background event page instead of service worker).
