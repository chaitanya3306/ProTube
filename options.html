YouTube Data API key (Optional — unlocks full topic search)

Without a key, the extension uses Starter Mode (official YouTube channel RSS feeds, zero setup). Add a free YouTube Data API v3 key to search across all of YouTube with full duration, like-ratio, and multi-strategy discovery.

How to get a free YouTube Data API v3 key in 60 seconds
  1. Open Google Cloud Console and create a new project.
  2. Go to APIs & Services → Library, search for YouTube Data API v3, and click Enable.
  3. Go to APIs & Services → Credentials → Create Credentials → API key.
  4. Paste the key below and click Save changes.
